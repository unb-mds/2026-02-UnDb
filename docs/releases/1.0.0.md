# Release 1.0.0 — preparação

**Estado:** candidata a release; ainda não promovida para `main` nem publicada como tag.

## Entrega prevista

- Consulta pública de professores, disciplinas e turmas, busca e comparação.
- Cadastro com e-mail institucional, confirmação local por log e sessão autenticada.
- Avaliação estruturada com substituição da avaliação anterior da mesma combinação.
- Importação manual das turmas de graduação de todas as unidades disponíveis no
  formulário público do SIGAA, com registro de sucesso ou falha.

## Evidências

- Correções da importação integradas à `develop` pela PR #130.
- Validação em PostgreSQL isolado: 211/211 unidades consultadas com sucesso,
  6.555 linhas processadas e 6.554 turmas distintas em 2026.2.
- 99 testes do backend passaram na validação local; os checks da PR #130 passaram
  na execução final. Detalhes em
  [Validação da importação SIGAA](../estudos/validacao-release-1-sigaa-2026-09-24.md).

## Operação local da demonstração

1. Configure `backend/.env` conforme o README do repositório e inicie o Compose.
2. Execute a importação manual com `--todas-unidades`, ano e período desejados,
   conforme o [guia de operação](../operacao-importacao-sigaa.md).
3. Confirme o registro de importação com status `sucesso` e consulte os dados no app.

## Limites aceitos para a Release 1

- A atualização periódica automática (RF18) fica para a Release 2. O comando de
  importação manual e o histórico de execução permanecem disponíveis na 1.0.0.
- A confirmação de e-mail usa o adaptador local `console`; o envio externo está
  planejado para a Release 2.
- A aplicação roda localmente. Não há publicação web de produção nesta etapa.
