[PR #228](https://github.com/unb-mds/2026-02-UnDb/pull/228), já integrada em develop.

as disciplinas regulares do perfil. A mensagem explícita de nenhum docente
encontrado passa a ser classificada como perfil ausente, sem confirmar identidade.

Referência: [issue #207](https://github.com/unb-mds/2026-02-UnDb/issues/207) e
[diagnóstico e verificações](../estudos/correcao-periodos-verao-issue-207.md).

sem mudança de dependências.

piloto de Física 2026.2 usando o código corrigido no terminal para reavaliar as
pendências sem decisão humana. O deploy da API não atualiza o código de uma
sessão local antiga. União de UUIDs existentes permanece uma operação separada.

Após merge em main, marcar o commit integrado com v1.3.1 e retornar os ajustes
de versão e documentação a develop por PR. A correção funcional já está em develop.
