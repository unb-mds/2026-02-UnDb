# Template de ata de reunião

Use este arquivo como base para registrar reuniões do grupo.

## Como usar

1. Copie este arquivo para `docs/atas/AAAA-MM-DD.md` antes ou logo após a reunião.
2. Substitua os campos entre colchetes somente por informações confirmadas.
3. Registre decisões separadamente de propostas e pendências.
4. Para cada ação, informe responsável e prazo quando esses dados tiverem sido definidos.
5. Use `Não informado` quando um campo obrigatório não puder ser confirmado; não presuma participantes, decisões ou responsáveis.
6. Vincule Issues, Pull Requests e documentos relacionados quando a relação tiver sido confirmada.
